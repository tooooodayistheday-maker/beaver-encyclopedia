WorksHub+ 內容 API v1

兩組 GET-only、伺服器對伺服器 API。憑證另行提供，本文不含金鑰。第一版是公開 GitHub Pages JSON；第二版支援驗證、查詢與游標分頁。

中台欄位對應

  • 資料陣列路徑：data（JSONPath：$.data）
  • 下一頁游標回應路徑：next_cursor（JSONPath：$.next_cursor）
  • 下一次請求的 query 名稱：cursor
  • next_cursor = null 停止抓取。空 cursor 視為第一頁；不要自行拆解或修改游標。
  • total 是篩選後、分頁前的總筆數；每頁筆數是 data.length。

這裡提供常見的根層 next_cursor 格式。仍需你在 WorksHub+ 建測試連接器，確認中台實際接受的游標設定。

第二版驗證：每次擇一

Authorization: Bearer ${BEARER_TOKEN}

X-API-Key: ${API_KEY}

Authorization: Basic ${BASE64_USERNAME_COLON_PASSWORD}

Basic 請在中台分別填入 username 與 password，由中台組出 Base64。請勿把憑證放在 URL/query 中。Worker 憑證只由環境 Secret bindings 讀取，不寫進程式、公開檔案或本文。每組服務使用各自的測試憑證。若同時送 Authorization 與 X-API-Key，回 401，避免驗證方式混淆。

HTTP 401
{"error":{"code":"unauthorized","message":"缺少或無效的驗證憑證；請擇一使用 Bearer、X-API-Key 或 Basic Auth。"}}

清單查詢參數

參數規則
limit預設 20；1–50 的整數，超過範圍回 400。
cursor使用上一頁回應的 next_cursor；其他篩選條件維持一致。可以調整 limit。
category分類名稱或 categories 回應的 id，例如 psychology、engineering、integration-test。空白表示不篩選。
q標題、摘要、情境與正文的關鍵字；不區分英文字母大小寫，上限 200 字元。
updated_afterISO 日期或含時區的完整時間；僅回 updated_at 嚴格晚於該時間的資料。只有日期時，視為台灣時間 00:00:00。使用 URL encoding，避免 +08:00 的加號變成空白。

清單依 published_date 降冪、id 降冪排序。改變 category、q 或 updated_after 後，必須清除 cursor。資料來源更新使游標快照過期時回 400/cursor_expired，請從第一頁重抓。未支援或重複的參數回 400。

第一版固定 JSON 路徑

詞彙網站：
/api/v1/words.json
/api/v1/words/017.json
/api/v1/words/latest.json
/api/v1/words/random.json
/api/v1/categories.json

河狸網站：
/api/v1/facts.json
/api/v1/facts/orange.json
/api/v1/facts/latest.json
/api/v1/facts/today.json
/api/v1/categories.json

第一版所有清單一次回傳全部資料，next_cursor 固定 null，不驗證金鑰、不支援即時計算查詢參數。random.json/today.json 是匯出時選定的快照，不是每次請求重新抽選。第一版不存在的檔案由 GitHub Pages 回 404，無法保證其錯誤頁為 JSON；統一 JSON 錯誤與 HTTP Content-Type 請以第二版為準。

測試資料與更新規則

兩組 API 都有 id=integration-utf8、category=整合測試、is_test=true 的測試紀錄，含中文、emoji 🦫📚🔎、引號、換行與超過千字的正文。可用單筆 API 或 ?category=integration-test 取得。這些資料不會加入原網站首頁的詞庫、不會發布 Threads，也不會被 latest、random、today 選中。

is_test 為額外的扁平布林欄位。source_count、分類 count、清單 total 均為數字；id 保持字串（017 不可轉為 17）。測試紀錄沒有研究來源，因此 source_count=0，來源欄位為空字串；部分河狸網站原生文章沒有 Threads 貼文，threads_url 也會是空字串。

updated_at 是「API 公開內容最後異動時間」，不是排程執行時間；相同內容重建不會改時間。首次匯出使用匯出時間，往後依內容差異追蹤。published_date 保留原發布日期；河狸原生卡片以 Git 歷史首次加入網站的日期為依據。來源快取最多約 60 秒，另受 GitHub Pages 發布與快取時間影響。

random 每次從正式詞彙抽選，可能連續抽到同一詞。today 依台灣日期與當時資料集穩定選取同一筆；若資料集變動，結果可能變更。完整資料欄位保持平鋪，來源總數與主要來源分開提供。

錯誤回應

{"error":{"code":"not_found","message":"找不到這筆資料。"}}
{"error":{"code":"invalid_parameter","message":"limit 必須是 1 至 50 的整數。"}}
{"error":{"code":"invalid_cursor","message":"游標無效；請清除 cursor 從第一頁開始。"}}
{"error":{"code":"cursor_expired","message":"資料已更新；請清除 cursor 重新讀取。"}}

第二版所有回應為 application/json; charset=utf-8。401 驗證失敗；400 查詢或游標錯誤；404 路徑/資料不存在；405 非 GET；502 公開來源異常；503 執行環境尚未設定完成。不設定 CORS。成功與錯誤皆不快取給共用代理。
